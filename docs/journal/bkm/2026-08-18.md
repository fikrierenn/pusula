- **Ratchet ilk tanımı "alım↑ + satış↓"** → HP kümesini KAÇIRDI. - **"Kanal kırılması B-139'un (matara/ajanda) kök sebebi"** iddiam → ÖLÇÜMLE ÇÜRÜTÜLDÜ. Kırılma %94,5 KİTAP kategorisinde; Kat3 10/12/16'da depo-sevk akışı düşmedi (3,63→3,43M ₺/ay = toptan). B-139 gerçek model zaafı olarak duruyor.

- **"Düşük onay oranı = alıcı olmayan hesap"** hipotezi → ÇÜRÜK. sirac.yigit %14 onaylı ama Özlüce md yrd (meşru karar verici). Düşük onay hesabın rolünü değil taleplerin reddedildiğini gösterir; "onay = formalite" tespiti de yumuşatıldı (onay seçici çalışıyor).
- **`irs.gKisi` ile kişiye atıf** → mal kabul personeli (GMY teyidi), alıcı değil. Kullanılsaydı haksız suçlama olurdu.
- **`urn.alimIadeYok` kolonu** → ölü kolon (138.920 ürün tek değer), ürün-bazlı iade hakkı yok. Tedarikçi bazlı `frm.frmIadeKural` kullanılmalı.
- **`CROSS APPLY (SELECT SUM(t.birim - o.en_az) ...)`** → SQL hatası "toplanmış deyimde dış başvuru + birden çok sütun" (aggregate-outer-reference kısıtı). Çözüm: ön-toplama temp tablosu (`#fz`), en_az JOIN kolonu olarak gelir.
- **`CONVERT(decimal(6,1), yüzde)`** → aritmetik taşma (uç fark %99999'u aşıyor). `decimal(12,1)`.
- **Kategori-payı için satır-başı korelasyonlu alt-sorgu** → 24,9 saniye. Tek GROUP BY + payı dışarıda hesapla.
- **Razor `else { @{ var ... } }`** → RZ1010 "Unexpected { after @". Çözüm: hesaplananları `@code` bloğunda computed property yap.
- **Bash heredoc (`<<'MD'`) ile uzun Türkçe markdown** → tırnak/karakter yüzünden "unexpected EOF". Write tool kullan.
- **Python `print()` ile kutu-çizgi karakteri (├──)** → cp1254 stdout hatası, script yarıda kaldı. Çıktıyı ASCII tut.
