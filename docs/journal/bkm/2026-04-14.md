## Öğrenilen Kritik Bilgiler

### Linked Server Tarih Tuzağı
- Linked server (ODAKJOKER.JOKER) tarih formatı: `YYYYMMDD` ISO ZORUNLU.
- DMY (`'13.04.2026'`) sessiz yanlış eşleşme yapıyor — MS OLEDB locale problemi.

### Müşteri Zinciri
- `J_ORDERS.CLIENTREF → J_ORDER_CLIENTS.LOGICALREF → CUSTOMERREF`.
- `CLIENTREF` per-order cari (max 3 tekrar), master müşteri DEĞİL.
- `J_ORDER_CLIENTS` = `J_CLCARD` birebir senkron. Standart: `J_ORDER_CLIENTS`.

### ISO Hafta Hesabı
- `DATEDIFF(DAY, '20251229', CAST(ORDERDATE AS date))/7 + 1` — DATEFIRST bağımsız.

### Kanal Değerleri
- `J_ORDERS.APPLICATION`: `'Mobil Uygulama (Android)'`, `'Mobil Uygulama (iOS)'`, `'Mobil Site'`, `'Web Sitesi'`.
