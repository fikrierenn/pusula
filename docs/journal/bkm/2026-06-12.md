- **sema STATUS kod ailesi** (bc47686): 1xxx=sipariş başlık · 2xxx=sipariş detay · 3xxx=Odak başlık · 4xxx=Odak detay. J_ORDERS.STATUS ∈ {1xxx,3xxx}, J_ORDER_DETAILS.STATUS ∈ {2xxx,4xxx}.
- **sema sipariş yaşam döngüsü** (7b4976d): Sipariş gelir→Odak'a aktarılır(WMSAKTARMA=1)→Odak operasyon(durum sürekli güncellenir)→nihai. 3xxx/4xxx=ara(yaşıyor) · 1xxx/2xxx=nihai. **3004/3006 iade DEĞİL = Odak ara aşaması** — status hatasının iş-mantığı kökü.

### Domain knowledge (kalıcı — KRİTİK)
- **JOKER STATUS bin-basamağı = seviye:** 1=sipariş başlık, 2=sipariş detay, 3=Odak başlık, 4=Odak detay.
- **Odak = lojistik/fulfillment operatörü.** Sipariş Odak'a aktarılır, Odak operasyon yapar (3xxx/4xxx ara durumlar), iş bitince 1xxx/2xxx nihai.
- **WMS depo adres tipleri:** 0=Raf, 1=Mal Kabul(GR), 5=özel(JokerHavuz/TRNS/CK01). Depo stok=PIVOT.
- **WMS bekleyen toplama:** ihtiyaç = sipariş − raflanmış(J_DETAIL_BOXES). J_DEPO_TOPLANACAK + ORDERS.STATUS=1000 + DETAILS.STATUS IN (2000,2002,2003,2007).
- **cari özet:** stkFirma=570 (BKM ana yayın firması), depo mekan 12/4480/4835, alış ehTip(0,10,2,12) satış(1,3,4,5).
