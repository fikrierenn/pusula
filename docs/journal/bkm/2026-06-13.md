## İşe YARAMAYANLAR (denenen ama başarısız)
- **Ham volume sektör okuma** (`\.\D:` + ReadFile, buffered VE FILE_FLAG_NO_BUFFERING) → **err 50 ERROR_NOT_SUPPORTED**. Storage filter driver (AV/şifreleme) ham IO'yu blokluyor.
- **$MFT'yi dosya açma** (`\.\D:\$MFT`) → **err 5 access denied**. `SeBackupPrivilege` AdjustTokenPrivileges → **err 1300 NOT_ALL_ASSIGNED** (group policy token'dan sökmüş, admin bile alamıyor).

- **Native AOT** → MSVC C++ linker yok → fallback self-contained single-file.
- **Recursive ScanDir** → node_modules derinliği + cycle → **stack overflow** → iteratif worker-pool'a çevrildi.
- **WIN32_FIND_DATAW `long ftX` alanları** → 8-byte align → 4 byte padding → tüm offset kaydı (dosya boyutu 4.5 milyar GB çöp, isim bozuk) → **`Pack=4`** düzeltti.
