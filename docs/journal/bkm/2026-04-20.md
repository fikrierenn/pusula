# Oturum Günlüğü — 2026-04-20 (bkm) — Session 5 başlangıç

## Ana Konu
EncoreMerkez `IsValid` keşfi ve toplu SQL düzeltmesi, `Sales.LineCount` güvensizlik tespiti, indirim kolon ilişkisinin (Direct vs Campaign) çözümlenmesi, doğrulama formüllerinin oluşturulması ve 3 mağaza × 3 grupta fiili doğrulama.

## Tamamlananlar

### IsValid Keşfi ve Toplu SQL Düzeltmesi
- `SalesProducts.IsValid = false` satırların iptal/düzeltme olduğu keşfedildi.
- `Sales` header toplamları bu satırları zaten hariç tutuyor, ama `SalesProducts` üzerinde toplam alırken `IsValid=1` filtresi olmadan toplamlar şişiyor.
- `Sales.LineCount` üretim hatası tespit edildi — tüm satırları (iptal dahil) sayıyor. Gerçek ürün sayısı için CROSS APPLY pattern zorunlu.
- 7 SQL dosyası güncellendi:
  - `fis_detay_dogrulama.sql`
  - `3al2ode_performans_raporu.sql`
  - `10_10_sepet-karsilastirmasi.sql`
  - `10_03_magaza-bazli-ciro.sql`
  - `10_16_kasiyer.sql`
  - `10_17_saat-bazli.sql`
  - `kontrol_gun_bazli_detay.sql`

### İndirim Kolon İlişkisi Çözüldü
- `DiscountTotalDirect` = TOPLAM indirim (manuel + kampanya).
- `DiscountTotalCampaign` = sadece kampanya kısmı (Direct'in alt kümesi).
- `DiscountTotalIndirect` ≈ 0 (ihmal).
- Toplamda sadece `DiscountTotalDirect` — ikisini toplarsan çift sayarsın.

### Doğrulama Formülleri (IsValid=1)
- `SUM(TotalPrice)` = `Sales.GrossTotal - ABS(Sales.DiscountTotal)` ✓
- `SUM(DiscountTotalDirect)` = `ABS(Sales.DiscountTotal)` ✓
- `SUM(TotalPrice + DiscountTotalDirect)` = `Sales.GrossTotal` ✓
- 20.04.2026 verisinde 3 mağaza × 3 grup üzerinde doğrulandı.

## Öğrenilen Kritik Bilgiler

### IsValid Disiplini
- `SalesProducts.IsValid = false` → iptal satırı.
- Sales header toplamları (GrossTotal, DiscountTotal) bu satırları otomatik hariç tutar.
- SalesProducts üzerinde toplam alırken `WHERE IsValid = 1` ZORUNLU.

### LineCount Yasak
- `Sales.LineCount` GÜVENİLMEZ — iptal satırları dahil sayar.
- Doğru ürün sayısı: `CROSS APPLY (SELECT COUNT(*) FROM SalesProducts WHERE SalesId = s.Id AND IsValid = 1)`.

## Kararlar

- SalesProducts sorgularında `IsValid=1` filtresi standart — bundan sonra her sorguda olacak.
- `LineCount` yerine CROSS APPLY pattern tüm sorgularda uygulandı, yeni sorgularda da bu pattern kullanılacak.
- İndirim toplamında sadece `DiscountTotalDirect` — `DiscountTotalCampaign` ayrı kırılım istenmediği sürece kullanılmayacak.
