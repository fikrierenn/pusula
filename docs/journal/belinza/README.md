# Belinza — Oturum Günlükleri

Belinza projesine (BelOps — eski adı Belinza Tek Tuş) dair oturum kayıtları.

## Bağlam

Henüz dolu değil. Belinza için iş başladığında ilk oturumda buraya yazılır:
- Bağlantı bilgisi (sunucu, DB adı, izinli şema)
- Ana tablolar
- Kritik kurallar (DerinSIS'tekine benzer ama Belinza'ya özgü)
- BelOps skill'i ile çapraz referans

## Şu anki durum

Bu klasör boş. İlk oturum şablonu için `docs/journal/README.md`'ye bak.
